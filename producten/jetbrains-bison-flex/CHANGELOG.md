# Changelog Bison & Flex

Eén bron voor de change-notes in plugin.xml, de "What's new" op de Marketplace en posts (skill `update-tekst`).
De regels hieronder staan in het Engels omdat ze zo naar de winkel gaan.

## 2026.1.2 (18 nov 2026), CONCEPT tot keuring Daan
- Better: ready for newer IDEs. No deprecated API left (JetBrains flagged one or two uses in 2026.1.1).
- Better: the Structure view now uses only public API, so it keeps working in IntelliJ IDEA 2026.2 and later.
- Checked with Plugin Verifier against IntelliJ IDEA 2025.3 and 2026.2 and CLion 2026.2.

## 2026.1.1 (8 nov 2026)
- Fixed: when the IDE has no Register dialog, "Start free trial" in the Pro notification now opens the Bison & Flex page on JetBrains Marketplace.

## 2026.1.0 (8 nov 2026)
- First release. Bison/Yacc and Flex/Lex file types, highlighting, syntax errors, folding, Structure view, and go to definition, find usages and rename within a file.
- Pro: navigation, find usages and rename of tokens across grammar and scanner, and warnings for undefined and unused names, with a quick fix to remove unused ones.

## Korte post (CONCEPT, alleen via de hoofdchat)
Bison & Flex 2026.1.2 is out: a small update that keeps the plugin working in IntelliJ IDEA 2026.2 and later. No deprecated API left, Structure view on public API only. Free for Bison/Yacc and Flex/Lex highlighting, structure and navigation in JetBrains IDEs.
