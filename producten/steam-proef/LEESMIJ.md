# Steam: technische proef (geen product)

Olaf, 9 nov 2026. Taak "Testen" uit `platformen/steam/taken.md` (Hans): een test op een Windows-runner van GitHub Actions die de app echt start en schermafbeeldingen maakt. Dit is geen prototype van een richting (dat komt pas na de keuze van Thijs), alleen de basis die alle drie nodig hebben:
- kan een Godot 4-venster doorzichtig en zonder rand boven de taakbalk staan, met klikken erdoorheen buiten de strook;
- start het op een Windows-runner (zonder grafische kaart), en welk tekenstuurprogramma werkt daar;
- kunnen we het bureaublad fotograferen, met een echt venster (Kladblok) erachter, en hoeveel processor kost een simpele strook.

Workflow: `.github/workflows/steam-proef.yml`. Schermen: tak `schermen`, map `steam-proef/<tak>/`. Uitslag in `platformen/steam/logboek.md`.
