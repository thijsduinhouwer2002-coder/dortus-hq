Repo > **Settings** > General > **Social preview** > Edit > Upload an image: `platformen/abel/merk/social-1280x640-v2-nu.png` (1280 x 640, 129 kB; GitHub wil minder dan 1 MB). Doen bij `rollwright` en `click-joints`.
