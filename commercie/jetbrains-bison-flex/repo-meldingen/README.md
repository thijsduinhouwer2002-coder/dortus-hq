# Bison & Flex for JetBrains IDEs

![Bison & Flex: grammar and scanner support in CLion and IntelliJ IDEA](https://dortus.com/bison-flex/poster-v2.jpg)

Read and change Bison/Yacc grammars and Flex/Lex scanners in your JetBrains IDE with highlighting, syntax errors, folding, Structure view and navigation.

**Get it:** [JetBrains Marketplace, plugin 35901](https://plugins.jetbrains.com/plugin/35901-bison--flex), or in the IDE: Settings > Plugins > Marketplace, search "Bison".

**Free:** file types for `.y` `.yy` `.l` `.ll`, highlighting, syntax errors, folding, Structure view, go to definition, find usages and rename within a file.
**Pro, in addition:** navigation, find usages and rename of tokens across grammar and scanner, warnings for undefined and unused names with a quick fix. 30 day free trial.

## Report a problem or ask for a feature
This repository holds no code; it is the place for [issues](../../issues/new/choose). Please include your IDE and plugin version (Help > About, Settings > Plugins) and, if you can, a small grammar or scanner that shows the problem.

What changed in each version: see the Versions tab on the Marketplace page.
